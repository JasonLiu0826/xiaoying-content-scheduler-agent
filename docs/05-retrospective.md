# 开发复盘

## 当前观察

最容易出错的是把“模型正常结束”混同于“业务保存成功”，以及把模型生成的确认参数当成人工授权。方案将保存、授权和最终状态交给可验证的业务层，模型负责动作选择。

已有通用 Agent 能复用模型接入经验，但大规模 Runtime 的权限、记忆和桌面集成会增加笔试项目的审查成本，因此采用独立的小型循环。
