# 效果验证

当前为阶段 1 设计基线，尚未实现业务链路。不会把规划中的用例描述成已通过。

## 验证方法

1. 使用 Node 测试运行器验证真实业务函数、数据库事务、幂等、冲突与确认边界。
2. 使用离线模型替身验证完整执行链和故障注入，记录为 `mock`。
3. 配置真实模型后，固定合成资料，运行正常、冲突、资料不足、规则风险与保存失败场景；保留原始动作和工具结果。
4. 改变占用时段再运行，核对模型后续动作和最终状态。
5. 所有输出保存于 `examples/`，本文件随实际结果更新并链接证据。

## 当前限制

- 未配置真实模型凭据，真实模型决策效果尚未验证。
- 未提供界面或线上部署；均不属于本题必需范围。
- 后续任何失败、重试与未完成状态将保留在结果中，不用 Mock 结果冒充真实模型结果。
